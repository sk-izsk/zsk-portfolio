# Portfolio Images

This directory contains all the images used in the portfolio.

For this demo, we're using placeholder images that you can replace with actual portfolio images.

## Image Requirements:

- hero.jpg: 400x400px, personal photo for the home section
- portfolio-1.jpg to portfolio-6.jpg: Project screenshots (400x300px recommended)
- All images should be optimized for web (compressed)

You can replace these placeholder images with your actual portfolio images.
